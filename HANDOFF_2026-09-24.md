## 6. How to verify quickly

- **App version on phone:** `adb shell dumpsys package in.jenix.floodguard | grep version` → `versionCode=20 … versionName=1.0.19`
- **Web build live:** the `assets/index-*.js` in `APK/www/index.html` must match `curl -s https://app.floodguard.jenix.in/ | grep -o 'assets/index-[^"]*\.js'`
- **In-app update manifest:** `node -e "console.log(require('/root/projects/floodguard/repo/VPS/backend/app-release.json').android.version)"` on the VPS
- **RUB42 config state (read-only):** read `deviceConfigs` for `RUB42-AJ` in `repo/VPS/backend/data/floodguard_db.json`. On 2026-09-24: `config_version 13`, RS485 only, `device_reported` absent.

## 7. Operational cautions

- **Do not edit `data/floodguard_db.json` while `floodguard-api` runs.** The API holds the store in memory and flushes it on shutdown/autosave, so your edit gets overwritten. Use the admin API/UI; if a direct edit is unavoidable: `pm2 stop` → edit → `pm2 start` (brief downtime).
- **Sites are live.** No firmware OTA outside a scheduled maintenance window.
- Passwords are bcrypt-hashed; they cannot be recovered, only reset (Users → Reset PW).
