Why This Platform

Built for field reliability, government audit visibility, and multi-location incident command.

Offline-First Safety

Danger detection and alarm activation run locally on controller logic. Cloud failure does not block emergency warning.

Audit-Grade Accountability

Every action is logged with user, session, device, time, and context for traceable incident reconstruction.

Responsive Dashboard and PWA

Desktop dashboard remains fully responsive across mobile, tablet, and large screens with installable PWA support.

Smart Alert Logic

Stable trigger windows and sensor filtering reduce false alarms from splash, debris, or transient movement.

Network and SIM Diagnostics

Monitor Wi-Fi, gateway, internet, SIM registration, operator, signal quality, and fallback communication health.

Scalable Governance Model

Supports vendor, department, location admin, operator, viewer, and third-party monitoring structures.

Execution Snapshot

Detailed milestones are documented in PHASE_WISE_DELIVERABLES.md.

Phase 1: Firmware Safety Core

Sensor filtering, delayed danger confirmation, relay orchestration, local queue, and dry-run support.

Phase 2-3: Uplink and Backend

MQTT + HTTP fallback, secure auth, RBAC, incident lifecycle, and complete control action auditing.

Phase 4: Responsive PWA Dashboard

Theme-consistent desktop and mobile web UI with vessel animation, status glow, and action safeguards.

Phase 5-6: Android, FCM, and Hardening

Capacitor Android delivery, push notification matrix, OTA protection rules, and full regression testing.
