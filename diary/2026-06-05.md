## 4. VPS Backend Changes

### `VPS/backend/src/services/deviceService.js`
Added ALERT_ORANGE FCM push. Previously only DANGER_CONFIRMED and DANGER_AUTO_CLEARED triggered notifications.

```js
// Added — fires when firmware publishes ALERT_CONFIRMED event
if (event.event_type === 'ALERT_CONFIRMED') {
  notificationService.publishNotification('ALERT_ORANGE', event);
}
```

FCM event chain:
- `ALERT_CONFIRMED` → `ALERT_ORANGE` push → `⚠️ Flood ALERT — Water level rising. Stay alert.`
- `DANGER_CONFIRMED` → `DANGER_CONFIRMED` push → `🚨 Flood DANGER — Water level CRITICAL. Evacuate now.`
- `DANGER_AUTO_CLEARED` → `DANGER_AUTO_CLEARED` push → `✅ Flood Cleared`
