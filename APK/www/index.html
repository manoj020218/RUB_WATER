Android App Required for Device Setup

BLE-based device provisioning is only available in the FloodGuard Android app. Use the app to scan, provision, and register a new device to a location on the cloud.

Once the device is registered and linked to a location, all monitoring, controls, complaints, lifecycle management, and reports work fully right here in this web app.

1Install FloodGuard APK on an Android phone
2Login as Vendor → open Install tab
3Scan BLE → provision Wi-Fi → register device to location
4Return here — the device will appear on the Locations screen
